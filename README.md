# 🔵⬜ 01 Club – Formation Git et GitHub

Cours pour débutants, en 2 séances, présentés au **01 club**.

## 📚 Contenu

- **Séance 1** : sauvegarder son travail en local
  (`git init`, `status`, `add`, `commit`, `log`, `diff`)
- **Séance 2** : revenir en arrière et travailler avec les autres
  (`restore`, `revert`, branches, GitHub, conflits)

## 📂 Fichiers

- `cours-git-01-club.md` : cours de la séance 1
- `cours-git-seance2-01-club.md` : cours de la séance 2

## 👥 À qui s'adresse ce cours ?

Aux débutants, sans aucun prérequis.
